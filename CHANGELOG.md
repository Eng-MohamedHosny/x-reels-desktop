# Changelog

## 1.0.0 (2026-11-22)

The first public release.

- X's own Reels viewer and recommendations in any X tab you choose, centered on the screen
- Mouse wheel and keyboard controls: ↑ ↓ / J K to swipe, ← → to seek 5 s, Space, M, Esc
- Aurora popup with a single glowing switch and a Carbon keyboard shortcuts screen
- Wave animation with a blue edge glow when Reels turns on and off
- Toolbar icon turns X blue while Reels is on in the tab
- No `chrome.debugger`, no account, no data collection
